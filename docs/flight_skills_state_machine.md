# 高度与位置技能软件状态机

这是电脑端可测试的控制目标与状态机仿真，不是真机控制验证。模块不依赖 Arduino，不实现状态估计、PID、电机混控或硬件驱动，也没有接入现有 MAVLink 飞控入口。它接收上游给出的当前位置、安全状态和 `HealthySnapshot`，只输出受限的高度、水平速度、偏航和失效处置目标，供未来经过验证的真实控制器消费。

## 输入边界

- `beginAtArm()` 只能在上游已经解锁且确认落地时调用，并记录当时的本地 X、Y、高度和偏航。本地原点在本次任务中不再改变。
- 当前位置必须是有限值，时间戳不能晚于当前时间，数据年龄最多 100 ms。
- 光流、测距和气压数据只通过 `HealthySnapshot` 读取。原始值范围、质量和有效时间由传感器遥测层统一判断，状态机不重复验证。
- 上游安全状态必须持续确认：没有人工接管、电池健康、未倒置、心跳新鲜且安全门正常。

## 固定技能限制

| 技能 | 限制与输出 |
|---|---|
| 起飞 | 相对解锁高度大于 0 且不超过 1.0 m；开始前必须同时有健康测距和气压数据；水平速度为 0，保持解锁时偏航 |
| 悬停 | 持续时间大于 0 且不超过 5 s；高度和偏航保持开始时的值，水平速度为 0 |
| 机体系移动 | 单次合成距离大于 0 且不超过 0.5 m，水平速度大于 0 且不超过 0.25 m/s；必须同时有健康光流、测距和气压数据 |
| 偏航 | 相对角度非 0 且不超过 ±180°，速率大于 0 且不超过 30°/s；水平速度为 0 并保持高度 |
| 返回局部原点 | 只朝 `beginAtArm()` 记录的本地 X、Y 原点输出不超过 0.25 m/s 的本地水平速度，保持开始返回时的高度和偏航；它不是 GPS 返航 |
| 降落 | 水平速度为 0，普通下降请求限制为 0.20 m/s；只有落地状态和近地测距连续满足 500 ms 后才请求上锁 |

移动、偏航、起飞和返回的完成都需要上游当前位置到达目标容差；状态机不会因为命令发送了一段时间就声称飞机已经到达。悬停按批准的持续时间结束。

## 确定性超时和顺序

- 整个任务：60 s。
- 起飞：10 s；移动：10 s；偏航：10 s；返回局部原点：20 s；降落：20 s。
- 悬停自身最多 5 s，到时结束。
- 传感器数据有效时间沿用遥测层：光流 100 ms、测距 200 ms、气压 500 ms。
- 第一个技能必须是起飞；前一个技能完成后才能开始下一个；起飞不能重复。
- 请求编号必须非零且严格向前。重复编号、较旧编号、技能重叠、时间倒退或任何参数错误都会使任务失效。
- 任务一旦失效或进入失效降落，后续技能全部拒绝。

## 固定故障处置

| 故障 | 状态机输出 |
|---|---|
| 光流失效 | 水平速度立即变为 0，转入普通降落 |
| 测距失效但气压健康 | 转入冗余降落，下降请求限制为 0.15 m/s |
| 测距与气压同时失效 | 输出限制为 0.30 m/s 的紧急下降请求并立即中止任务 |
| 气压单独失效 | 转入普通降落 |
| 人工接管、低电、倒置、心跳超时或上游安全门故障 | 任务立即失效并输出中止目标，由已有上游安全门执行它自己的上锁或其他安全动作 |

冗余降落没有健康测距可用，因此只有上游落地判断为真、且本地高度连续 500 ms 接近解锁高度时才请求上锁。任何落地条件中断都会重新计时。降落超时会升级为受限紧急下降请求。

## 主机检查

```bash
./scripts/check_firmware.sh control
```

该检查编译并运行正常顺序、全部上限、越序、重复、任务和技能超时、时间倒退、传感器故障、安全故障及故障后阻断测试，并扫描软件模块是否引用现有电机、姿态或直控符号。检查通过只证明软件状态机按这些固定规则运行，不证明传感器、估计器、控制器或真机飞行已经验证。
