# 传感器遥测与健康状态接口

这是一层可在电脑上验证的数据接口，不是传感器实物验证。当前仓库没有主板接口照片、引脚表、具体模块或接线证据；因此这里没有 PMW3901、VL53L1X、BMP388 驱动，也没有任何硬件可用的结论。

`sensor_telemetry.h` 定义三类驱动提交的样本：光流角速度、向下距离和气压计。每个样本都必须带毫秒时间戳、`detected`、`valid` 和 0–255 的质量值。`detected=false` 表示未探测；`valid=false` 表示预热或尚未产生可用数据，数值不会被读取。

聚合器固定执行以下失败关闭检查：

- 光流：每轴角速度必须是有限值且绝对值不超过 20 rad/s，数据年龄最多 100 ms。
- 向下距离：按目标 VL53L1X 固定为有限的 0.04–4 m，数据年龄最多 200 ms。
- 气压计：压力 30,000–110,000 Pa、温度 -40–85 °C、相对高度 -1,000–10,000 m，且均为有限值；数据年龄最多 500 ms。
- 三类样本的质量值都至少为 30；样本时间戳或请求快照的时间倒退时，当前快照标记为时间倒退，不能读取数值。

健康状态区分未探测、预热中、健康、过期、越界、质量不足和时间倒退。后续高度或位置技能只能接收 `HealthySnapshot`，并且必须检查 `opticalFlow()`、`range()` 或 `barometer()` 的返回值；失败时输出对象不会被写成 0。

`flight_skills.*` 正是通过这个健康快照读取三类数据。它不会重新解释驱动原始值，也不会延长这里固定的数据有效时间；数据过期、质量不足或时间倒退都会以“不健康”进入技能的失败处置。

未来真实驱动接入前仍需补齐并核实：模块型号与数据手册、主板接口照片、GPIO/I2C/SPI 接线、供电与电平、安装方向、实际量程和质量码映射。确认后，驱动只应把这些字段提交给 `TelemetryAggregator`；量程、时间和质量阈值如需调整，应伴随台架证据和主机测试更新。
