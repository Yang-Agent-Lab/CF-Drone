# E1 Flight Agent 机内安全门协议

本协议只建立 Agent 入口、解锁安全检查和停止能力。它不提供起飞、降落、悬停或移动控制，也不允许 Agent 直接写电机、姿态目标、参数或控制台命令。

## 固定 MAVLink 边界

- 消息：`COMMAND_LONG`（消息号 76）
- 项目私有命令：31010（MAVLink 用户自定义命令区）
- 飞控目标：系统号 1、组件号 1（`MAV_COMP_ID_AUTOPILOT1`）
- Agent 来源：系统号 42、组件号 191（`MAV_COMP_ID_ONBOARD_COMPUTER`）
- Agent 心跳发送间隔：不超过 250 ms
- Agent 心跳超时：1000 ms

固定来源号只能防止误接线和限制模型进入旧的直控入口，不是密码学身份认证。知道这些编号的其他发送方可以仿冒 Agent。

`COMMAND_LONG` 参数固定如下：

| 字段 | 含义 | 允许范围 |
|---|---|---|
| `param1` | 技能编号 | 下表中的整数 |
| `param2` | 请求编号，用于防止重复执行 | 1 到 16777215 的整数 |
| `param3` | 安全确认码 | 固定为 7319 |
| `param4` 到 `param7` | E3T1 未启用的技能参数 | 必须全为 0 |
| `confirmation` | MAVLink 重传计数 | 0 到 255；不代替 `param2` |

## 技能白名单

| 技能编号 | 名称 | E3T1 行为 |
|---:|---|---|
| 1 | Agent 心跳 | 建立或刷新会话 |
| 2 | 解锁 | 全部安全条件通过后才解锁 |
| 3 | 上锁 | 立即上锁并清零推力目标 |
| 4 | 急停 | 无条件上锁、清零推力目标并锁存故障 |
| 100 | 起飞 | 明确返回“尚未实现” |
| 101 | 降落 | 明确返回“尚未实现” |
| 102 | 悬停 | 明确返回“尚未实现” |
| 103 | 机体系移动 | 明确返回“尚未实现” |
| 104 | 偏航 | 仅加入高层白名单，当前入口仍明确返回“尚未实现” |
| 105 | 返回局部原点 | 仅加入高层白名单，当前入口仍明确返回“尚未实现”；不是 GPS 返航 |

重复的已执行请求返回成功但不会再次执行。未知技能、错误确认码、错误参数、错误目标或其他 Agent 消息会锁存故障。锁存后 Agent 不能再次解锁；E3T1 不提供 Agent 自行清除故障的命令，需要人工检查后重启飞控。

E3T3 新增的电脑端飞行技能状态机没有接入这条 MAVLink 入口。它只验证技能顺序并生成受限目标；在真实控制器、状态估计和硬件验证完成前，以上高层技能在飞控入口仍保持“尚未实现”，不会写入电机、姿态目标或旧直控通道。

## 解锁和运行时检查

解锁前必须同时满足：

- 飞控当前未解锁；
- 油门不高于 5%；
- 姿态有效且四元数长度在 0.9 到 1.1 之间；
- 机体未倒置；
- IMU 初始化成功；
- 单节电池电压在 3.5 V 到 4.4 V 之间；
- 飞控判断机体已经落地且静止；
- Agent 心跳未超过 1000 ms；
- 没有人工遥控输入；
- 没有已锁存故障。

Agent 会话中发生心跳超时、人工遥控介入、低电、倒置、姿态失效、未知技能或非法消息时，安全门进入锁存故障状态。若当前解锁由 Agent 发起，则立即上锁并清零推力目标。人工遥控和急停优先于 Agent；Agent 未取得解锁权时，安全门不会改写非 Agent 的既有人工遥控行为。

## 必须拒绝的 Agent 消息

来自固定 Agent 来源的 `MANUAL_CONTROL`、`PARAM_SET`、`SERIAL_CONTROL`、`SET_ATTITUDE_TARGET`、`SET_ACTUATOR_CONTROL_TARGET`，以及通用解锁、改模式命令，全部在旧处理分支之前拒绝。来自其他来源的原有人工遥控处理保持不变。

飞控使用 `COMMAND_ACK.result` 返回 MAVLink 标准结果，并在 `COMMAND_ACK.result_param2` 返回安全门结果编号。0 表示接受，1 表示重复请求，10 表示白名单技能尚未实现，20 到 27 表示当前安全条件不满足，30 到 33 表示已锁存或协议违法。

本改动沿用上游 `songge8/CF-Drone` 的飞控实现和仓库 `LICENSE`，保留琛光品牌及原启动文字。
